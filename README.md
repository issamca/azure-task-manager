# 🚀 Azure Task Manager

Aplicação serverless desenvolvida na Microsoft Azure para gerenciamento de tarefas.

## 📋 Sobre o Projeto

Este projeto foi criado com o objetivo de demonstrar conhecimentos em:

- Azure Functions
- Azure Cosmos DB
- Azure Static Web Apps
- GitHub Actions
- Python
- APIs REST
- CI/CD

## 🚀 Como Executar

```bash
git clone https://github.com/issamca/azure-task-manager.git
```

```bash
cd azure-task-manager
```

Instalar dependências:

```bash
pip install -r requirements.txt
```

Iniciar Azure Functions:

```bash
func start
```
